ST MARIS HIGH SCHOOL - WORDPRESS THEME

INSTALL
1. WordPress admin > Appearance > Themes > Add New > Upload Theme.
2. Choose st-maris-theme.zip > Install Now > Activate.
3. On activation the theme creates the pages (Home, About Us, Academics,
   Gallery, Contact Us, Apply), sets Home as the front page and builds the menu.

EDIT SCHOOL DETAILS (address, phone, email, hours)
Appearance > Theme File Editor > functions.php > function stmaris_info()

FORMS
Contact and Apply forms email the address set in stmaris_info().
If emails do not arrive, install the free "WP Mail SMTP" plugin.
